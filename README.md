# SAMIYA BEAUTY LAB

Kosmetika ta'limi va ingredient (INCI) ma'lumotlari ilovasi (UZ, RU, EN, AR).

- `mobile/`: Flutter ilova. `cd mobile && flutter analyze && flutter test --exclude-tags visual`
- `backend/`: Cloudflare Worker. `cd backend && npm ci && npm test`
- `content/`: ingredient kartochkalari (manbalar bilan) va tekshiruv vositalari
- `design/`: brend va ekran referenslari. `docs/`: qarorlar va holat (`docs/STATUS.md`)
